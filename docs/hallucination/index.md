# Hallucination Module

[TOC]

## Overview

The Hallucination Module provides a **unified, modular, and extensible framework** for detecting and evaluating hallucinations in **Large Language Models (LLMs)** and **Vision-Language Models (VLMs)** across diverse generation tasks and application scenarios.

The module targets both text-based and multimodal generation settings. By combining structured content decomposition with tool-augmented verification and multi-granularity result aggregation, it enables systematic and interpretable evaluation of hallucinations such as factual errors, reasoning mistakes, computational errors, and cross-modal inconsistencies.



## Supported Hallucination Types

The module supports multiple representative hallucination detection scenarios defined following the FacTool task formulation, covering high-frequency hallucination patterns in common generation tasks.

### 1. Knowledge-based Hallucination (KB-QA)

- **Applicable scenarios**: Factual question answering, knowledge-intensive generation, explanatory and encyclopedic responses  
- **Detection target**: Verifiable atomic factual statements (claims) within model outputs  

**Detection procedure**:
1. Extract independent, verifiable factual claims from the generated response  
2. Construct retrieval queries for each claim  
3. Acquire supporting evidence via external retrieval tools  
4. Determine whether each claim is supported or contradicted by the evidence  

**Outputs**:
- Claim-level: support / non-support judgment for each factual claim  
- Response-level: whether the response contains factual hallucinations  

### 2. Code Hallucination

- **Applicable scenarios**: Code generation, program synthesis, function implementation and completion  
- **Detection target**: Code snippets or complete programs generated by the model  

**Detection procedure**:
1. Treat the generated code as a verification target  
2. Construct or generate test cases  
3. Execute the code and collect runtime results  
4. Verify whether the observed behavior satisfies the expected specifications  

**Outputs**:
- Pass/fail test results  
- Error categories (runtime errors, logical errors, boundary condition failures, etc.)

### 3. Math Hallucination

- **Applicable scenarios**: Mathematical reasoning, step-by-step problem solving, numerical and symbolic computation  
- **Detection target**: Individual computation steps or equations in the reasoning process  

**Detection procedure**:
1. Decompose the full reasoning chain into independent computation steps  
2. Convert each step into an executable mathematical expression  
3. Execute and verify the correctness of each computation  

**Decision rule**:
- The presence of any incorrect computation step indicates a mathematical hallucination in the generated response  

**Outputs**:
- Localization of incorrect steps  
- Step-level correctness statistics  

### 4. Citation Hallucination (Sci-Review)

- **Applicable scenarios**: Academic surveys, literature reviews, professional technical reports  
- **Detection target**: Citation metadata tuples (e.g., title, authors, year)  

**Detection procedure**:
1. Extract citation metadata from the generated text  
2. Retrieve ground-truth bibliographic records using academic search tools  
3. Compare consistency across titles, author sets, and publication years  

**Decision rules**:
- Title and year must satisfy consistency constraints  
- Author information must match exactly or satisfy a reasonable subset constraint  

## Metrics

### Core Metrics

- **hallucination_rate**: proportion of incorrect claims  
- **response_hallucination_rate**: proportion of responses containing hallucinations  
- **claim_coverage**: fraction of claims successfully entering the verification pipeline  
- **evidence_hit_rate**: proportion of claims for which supporting evidence is retrieved  

### Task-specific Metrics

- Knowledge: factual support rate  
- Code: test pass rate  
- Math: step-level correctness rate  
- Citation: citation consistency rate
