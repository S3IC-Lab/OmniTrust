## 📋 改进内容

### 1. 统一模型管理（jailbreak.py）
```python
# 第 11-12 行：导入模型管理模块
from model.llm import get_supported_llm
from model.model_configs import model_configs

# 第 21-22 行：一行代码载入模型
model_caller = get_supported_llm(yaml.safe_load(open(
    model_configs.get(args.model_name, args.model_config_path), 'r'
))) if not args.use_custom_api else None

# 第 29-30 行：将模型调用器传递给攻击方法
attack_model = MultilingualModel(args, args.model_name, model_caller)
```

### 2. 统一数据集管理（jailbreak.py）

```python
# 第 13 行：导入数据集注册表
from data.data_registry.registry import DatasetRegistry
```

### 3. 攻击方法适配统一模型系统（Multilingual_attack.py）
```python
# 只接收 args 和 model_caller 参数（删除了不必要的 model_name）
def __init__(self, args, model_caller):
    super().__init__(args, model_caller)
    self.model_caller = model_caller

# 使用统一的模型调用器
def get_harmful_prompt_and_response(self, prompt):
    messages = [{"role": "user", "content": self.harmful_prompt}]
    result = self.model_caller.generate(messages)
    self.response = result[0].get('generation', '').strip()
```

### 4. 基类也已更新（AttackBase.py）
```python
class AttackInterface(ABC):
    def __init__(self, args: Any, model_caller: Any):
        """统一接收 model_caller，不再需要 model_name"""
        self.args = args
        self.model_caller = model_caller
```

## 🚀 使用方式

### 基本使用

```bash
# 设置 API 密钥
export OPENAI_API_KEY="sk-your-key"

# 运行攻击
python examples/jailbreak.py \
    --model_name chatgpt \
    --attack Multilingual \
    --data_path data/dataset/jailbreak_test.json
```

### 参数说明

**模型参数**:
- `--model_name`: 模型名称（如 `chatgpt`, `gpt4`, `Qwen2-7B-Instruct`）
- `--model_config_path`: 自定义配置文件路径（可选）

**数据集参数**:
- `--data_path`: 数据集文件路径（支持 `.json` 和 `.jsonl` 格式）

**攻击参数**:
- `--attack`: 攻击方法（目前支持 `Multilingual`）
- `--mutation_language`: 变异语言（如 `zh-CN`, `fr`, `es`）

## 📁 数据集格式

### JSON 格式
```json

    {"prompt": "How to hack a website?"}
```
